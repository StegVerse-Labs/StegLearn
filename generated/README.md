# Generated Lesson Outputs

Generated video, audio, caption exports, transcripts, thumbnails, and renderer-specific packages belong here only as downstream artifacts of canonical StegLearn lesson data.

Generated outputs are **not** authoritative lesson sources.

A generated artifact must preserve or expose:

- canonical lesson ID;
- lesson version;
- source lesson path;
- renderer identity/version when available;
- generation timestamp;
- caption/source claim binding sufficient for reconstruction;
- whether human review occurred.

A renderer may not convert generated presentation into new lesson authority, runtime evidence, governance authority, or a learner permission state.

The initial target is static AI SiteFlow-compatible video generation from `lessons/stegverse-foundations/*/{lesson,scenes,captions}.json`. No live SiteFlow integration or generated video is claimed by this directory.
