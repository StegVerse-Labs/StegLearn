# 01 — What Is StegVerse?

Canonical lesson ID: `steglearn.stegverse-foundations.01`

This is the first materialized StegVerse Foundations lesson. It is designed to be renderable as a static AI SiteFlow video, transcript, caption track, or later interactive StegLearn tutorial without allowing the renderer to redefine the lesson.

## Objective

The learner should be able to explain StegVerse as governance infrastructure, distinguish capability from authority, and recognize the ecosystem contribution classes without treating them as automatic permissions.

## Canonical source

- `StegVerse-Labs/.github/docs/ECOSYSTEM_PURPOSE_INVARIANT.md` — `CANONICAL / ACTIVE` organization-level purpose invariant.

The source controls the lesson's ecosystem-purpose claims. The lesson does not independently establish runtime status, implementation completeness, protocol adoption, or authority for any named StegVerse component.

## Package

- `lesson.json` — claims, source authority, objectives, checkpoint, receipt evidence targets, renderer restrictions, and version provenance.
- `scenes.json` — exact ordered presentation data: narration, canonical caption, visual instruction, claim binding, and `do_not_imply` constraints.
- `captions.json` — canonical English caption track. Every caption entry must exactly match its scene caption.

## Renderer boundary

`AI_SITEFLOW_STATIC_VIDEO` is the first intended rendering target, not the lesson authority.

A renderer may compose timing, typography, transitions, voice, and compatible visuals. It may not invent claims, silently paraphrase claims where prohibited, change authority semantics, convert source/build evidence into runtime claims, or make generated output canonical without StegLearn review.

## Learning evidence

Completion may support a parent/steward-reviewed receipt showing that the learner:

- explained the purpose of StegVerse in their own words;
- distinguished capability from authority;
- identified ecosystem contribution classes without turning them into permission claims.

Completion does not grant authority or establish a permanent learner label.
